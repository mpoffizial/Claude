# Projekt-Kontext

Dieses Repository enthält zwei Bereiche:
- **Trading** (Pine-Strategien, Backtests, `polymarket_btc_bot/`) – siehe `SETUP.md`.
- **Modemarke OYMYAKON** – Markenhandbuch in `brand/README.md`, 3D/Blender in `jacket_3d/`.

## Wenn es um die Marke OYMYAKON geht
- Zuerst `brand/README.md` lesen (Name, Logos, Farben, Schriften, Logo-Positionen, Produkte).
- **Websites:** immer nach `brand/website_blueprint.md` bauen – Higgsfield `website-builder-flow`
  (`get_workflow_instructions`), Typ `website`, Pipeline Phase 0–6, Brand-Vorgaben übernehmen.
  Ziel: mindestens so gut wie https://oymyakon.higgsfield.app, idealerweise besser (Ideen im Bauplan).
- **Neue Kleidungsstücke:** Ablauf aus `brand/README.md` ("Nächste Produkte"), Skript `jacket_3d/build_jacket_scene.py` wiederverwenden.
- Mit dem Nutzer auf Deutsch sprechen.
